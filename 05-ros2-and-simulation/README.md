# LEVEL 5: ROBOT THÔNG MINH VỚI ROS2, MÔ PHỎNG & ĐIỀU HƯỚNG TỰ ĐỘNG

> **Mục tiêu**: Xây dựng hệ sinh thái robot hoàn chỉnh theo chuẩn công nghiệp với ROS2 (Humble / Jazzy), mô phỏng 3D trong Gazebo, kết nối vi điều khiển với Micro-ROS, lập bản đồ thời gian thực SLAM và điều hướng thông minh Nav2.

---

## 📚 DANH SÁCH BÀI HỌC DỰ KIẾN

- [ ] **Bài 01**: Kiến trúc ROS2: DDS Middleware, Nodes, Topics, Services, Actions & Khác biệt với ROS1.
- [ ] **Bài 02**: Cầu nối Phần cứng Micro-ROS: Chạy ROS2 Node trực tiếp trên STM32/ESP32 qua UART/USB.
- [ ] **Bài 03**: Mô hình hóa Robot: Ngôn ngữ URDF, Xacro, Joints, Links và trực quan hóa trong RViz2.
- [ ] **Bài 04**: Mô phỏng vật lý 3D với Gazebo: Cảm biến ảo Lidar, Camera, ma sát mặt đường và trọng lực.
- [ ] **Bài 05**: Thư viện biến đổi hệ tọa độ TF2: Cây tọa độ `map` -> `odom` -> `base_link` -> `laser`.
- [ ] **Bài 06**: Lập bản đồ tự hành SLAM: Cảm biến LaserScan 2D, SLAM Toolbox và Cartographer.
- [ ] **Bài 07**: Điều hướng tự động Nav2: Costmaps (Global/Local), AMCL Localization, DWB Controller & Behavior Trees.
