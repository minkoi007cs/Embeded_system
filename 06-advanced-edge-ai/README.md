# LEVEL 6: DỰ ÁN CAPSTONE THỰC CHIẾN, EDGE AI & EMBEDDED LINUX

> **Mục tiêu**: Tích hợp toàn diện phần cứng nhúng, hệ điều hành thời gian thực, thuật toán điều khiển và trí tuệ nhân tạo biên (Edge AI / TinyML) vào các dự án hoàn chỉnh đạt chuẩn công nghiệp.

---

## 📚 DANH SÁCH DỰ ÁN & BÀI HỌC DỰ KIẾN

- [ ] **Dự Án Capstone 01**: Xây dựng xe tự hành Autonomous Mobile Robot (AMR) vi sai tích hợp Lidar SLAM, Nav2 và STM32 Micro-ROS low-level controller.
- [ ] **Dự Án Capstone 02**: Cánh tay Robot 4-DOF / 6-DOF kết hợp thị giác máy tính OpenCV gắp thả vật thể (Pick-and-Place).
- [ ] **Chuyên đề Edge AI**: Triển khai mạng nơ-ron nhận diện cử chỉ/âm thanh với TensorFlow Lite for Microcontrollers (TinyML) trên vi điều khiển.
- [ ] **Chuyên đề Embedded Linux**: Xây dựng Custom Linux Image cho Raspberry Pi/BeagleBone với Yocto / Buildroot.
- [ ] **Chuẩn Kỹ sư Chuyên nghiệp**: Unit Test firmware với Unity/CMock, tài liệu hóa với Doxygen và luồng CI/CD tự động build firmware trên GitHub Actions.
